8. Session ID Validation
────────────────────────────────────────

Provider metadata is untrusted.

Implement one strict parser that is the only supported
way to produce ValidatedSessionId.

Use lowercase UUID syntax only.

Recommended shape:

^[0-9a-f]{8}-[0-9a-f]{4}-[1-8][0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$

Do NOT:

- lowercase an invalid value
- trim command fragments into validity
- accept session names
- accept arbitrary text
- accept paths
- accept flags
- accept uppercase UUIDs in this MVP

Reject rather than normalize.

The original discovered full ID remains unchanged.
